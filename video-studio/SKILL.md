# Video Studio · 视频工作室

一句话 → 分镜 → 时间线 → 成片。把"做个视频"变成可执行的工程。

## 何时使用

- 用户给出主题或一句话，需要一支视频
- 已有素材（图片/录屏/口播），需要组织成片
- 需要判断一支视频"该怎么剪"的方案

## 工作流

### 第 1 步：定三件事（1 分钟内确认）
- **时长**：宣传片默认 30-90 秒，超 2 分钟先问
- **画幅**：横屏 16:9 通用；投社交信息流默认竖屏 9:16
- **节奏**：一支视频只讲一件事，一句话说不清就砍

### 第 2 步：分镜脚本
按 4-8 个镜头拆，每个镜头固定四要素：

```
镜头 N ｜ 时长 ｜ 画面（看到什么）｜ 口播/字幕（听到什么）｜ 目的（为什么存在）
```

删不掉任何一个"目的"的镜头才是必要镜头。

### 第 3 步：时间线装配
三条轨道对齐秒表：
- **画面轨**：每个镜头的起止，转场不超过 0.4s
- **文案轨**：口播逐句对齐画面，一句 ≤ 15 字，关键数字放大
- **声音轨**：音乐情绪跟随段落，人声出现时音乐自动让位

### 第 4 步：渲染与验收
渲染后必须实际回放检查：首帧是否抓人、关键信息是否在黄金 3 秒内出现、结尾是否给出行动点。看过的才叫成片，渲染成功不等于验收通过。

## 质量检查

- [ ] 每个镜头都有明确"目的"，删掉任何一个都会伤害叙事
- [ ] 前 3 秒出现钩子（问题/数字/反差）
- [ ] 口播朗读时长与镜头时长对得上（中文约 4 字/秒）
- [ ] 结尾有明确的下一步（访问/安装/关注）

## 输出格式

分镜表 + 时间线 + 成片文件（如可渲染）。交付时附一句"这支片子的钩子是什么"。
