# Growth Miner · 社区增长

产品 → 社区扫描 → 意图匹配 → 个性化回复。在别人真诚提问的地方，先真诚给价值。

## 何时使用

- 产品冷启动找种子用户
- 监测"求推荐 XX 工具"类高意向帖
- 收集用户对竞品的真实抱怨（需求信号）

## 工作流

### 第 1 步：定义信号
把产品翻译成"什么样的人在什么样的帖子里会需要它"：

```
人群（谁）｜ 场景（遇到什么问题）｜ 触发句式（帖子里大概会怎么问）
```

### 第 2 步：扫描与匹配
- 流览帖子流，区分三类：**真诚求推荐** / 泛讨论 / 无关闲聊
- 只对第一类生成回复，附意图匹配置信度
- **低于 80% 置信度的直接放弃**——硬蹭的广告帖比不发更伤品牌

### 第 3 步：价值优先回复
回复结构（不许颠倒）：
1. 先直接回答对方的问题（哪怕推荐的不全是自家产品）
2. 补充一个相关经验/数据点
3. 最后一句才自然提到自家产品，且给出"什么情况下适合你"
- 长度 ≤ 120 字；不说"我们团队强大"类空话

### 第 4 步：记录与复盘
- 每条回复记录：帖子链接、发布时间、后续互动数
- 7 天后回访：哪类触发句式的转化最好，更新第 1 步的信号定义

## 质量检查

- [ ] 每条回复先给价值再提产品，读起来不像广告
- [ ] 低置信度帖已放弃，数量宁可少
- [ ] 回复内容与帖子具体内容强相关，不是万能模板
- [ ] 无任何伪装身份（如实以产品身份或个人身份，遵守社区规则）

## 输出格式

可回复清单（帖子摘要 + 置信度 + 回复草稿）+ 一句复盘建议。
