# Media Forge · AI 媒体生成

描述 → 提示词工程 → 生成队列 → 资产管理。又快又省地拿到能用的素材。

## 何时使用

- 文章/页面/视频需要配图、封面、插画
- 需要多风格变体供挑选
- 已有素材需要变体、放大、风格化

## 工作流

### 第 1 步：需求翻译
把用户的口语描述翻译成结构化提示词，五要素：

```
主体（是什么）｜ 构图（什么视角/景别）｜ 光线（时间与氛围）｜ 风格（参考艺术方向，不引用具体品牌）｜ 约束（避免什么）
```

### 第 2 步：小步快跑
- 先生成 **1 张低成本小样** 确认方向，方向对了再批量
- 一次生成 2 个差异化变体（不是同参数重跑）
- 用户没批准的重试不自动发起——花钱的操作必须对齐数量

### 第 3 步：队列管理
生成任务是异步的：提交 → 轮询原任务状态 → 失败先查原因再决定是否重试。**绝不向未知结果的任务自动重复提交**（可能重复扣费）。

### 第 4 步：资产入库
- 每个资产带版本，引用时锁定精确版本
- 命名用人话：内容 + 用途（如「霓虹城市-宣传片头图」），不用乱码
- 不合格素材直接标记淘汰，不入库占位

## 质量检查

- [ ] 提示词五要素齐全，没有出现具体品牌/在世艺术家名
- [ ] 先小样后批量，重试有数量上限
- [ ] 交付时说明每张图的用途与建议尺寸

## 输出格式

资产文件 + 一行用途说明。多方案时给 2-3 个变体让用户选，不要自作主张只交一张。
