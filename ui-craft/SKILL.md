# UI Craft · 界面生成

简报 → 有意图的界面 → 规范自检。生成的每个界面都该像人仔细做出来的。

## 何时使用

- 用户描述了一个产品/页面，需要看到界面
- 已有界面需要按规范复查
- 需要在亮/暗两态下都可用的界面

## 工作流

### 第 1 步：读简报，定气质
从简报提取：产品是什么、给谁用、情绪关键词（安静/锐利/专业/治愈）。气质决定字体大小节奏、圆角、留白密度——先定这个，再动手。

### 第 2 步：搭结构，再填样式
1. 先写信息层级：一屏里什么最重要？给到最大的视觉权重。
2. 布局要**有意图的不对称**：不要把内容均分成等宽卡片阵列。
3. 强调色只用于关键动作与关键数字，一个页面不超过一处大面积使用。

### 第 3 步：规范硬指标
- 间距全部落在 8pt 网格（8/16/24/32/48）
- 正文对比度 ≥ 4.5:1，大标题 ≥ 3:1
- 可点击元素触达区域 ≥ 44×44px
- 数字使用 tabular-nums，避免跳动

### 第 4 步：状态补全
每个交互元素必须有：默认 / 悬停 / 按下 / 禁用 / 加载中 五态。缺任何一态不算完成。

### 第 5 步：三道自检门
1. **眯眼测试**：模糊看，层级是否依然分明？
2. **撤掉颜色**：只看黑白灰，信息是否依然可读？
3. **塑料感检查**：有没有无意义的渐变、均匀卡片阵、装饰性阴影？有则删。

## 质量检查

- [ ] 亮/暗两态都检查过
- [ ] 五态齐全
- [ ] 8pt 网格、对比度、触达区域三项数值过检
- [ ] 页面上没有任何"看起来像 AI 生成的"均匀三栏卡片

## 输出格式

可运行的界面代码 + 一份简短的设计说明（气质定位、层级决策、规范自检结果）。
