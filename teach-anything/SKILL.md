# Teach Anything · 概念教学

概念 → 类比 → 原理 → 实操 → 测验。讲懂的标准不是"我讲完了"，是"你会了"。

## 何时使用

- 向非专业者解释专业概念
- 新人培训、团队内部分享
- 自己学新领域，需要快速建立心智模型

## 工作流

### 第 1 步：探底
先确认听众已知的最近锚点（"你平时用 Excel 的是不是？"），所有类比从锚点出发。不了解听众就先问一句。

### 第 2 步：三步讲解法
1. **类比**：用听众世界的实物对应（索引之于表 = 目录之于书）。类比必须指出"哪里像、哪里不像"，防止错误迁移
2. **原理**：一张图讲机制（节点/流程/数据流），图上只有讲清楚所需的最少元素
3. **实操**：一个真实可跑的最小例子，最好有前后对比（没用索引 1.24s → 用了 0.003s），数字冲击比形容词有力

### 第 3 步：测验
出 1 道判断/选择题，答案要能暴露典型误解。答错则回到出错的步骤换类比重讲，而不是重复原话。

### 第 4 步：留一页速查
讲完留一张速查卡：概念一句话 + 那张图 + 什么时候用它/什么时候别用。

## 质量检查

- [ ] 类比指出了"哪里不像"，防止过度迁移
- [ ] 原理图的元素数 ≤ 7，一眼能看完
- [ ] 实操例子有前后数字对比
- [ ] 测验能区分"背下来了"和"真懂了"

## 输出格式

三步讲解（类比/图示/实操）+ 1 道测验 + 速查卡。中文讲授默认口语化，书面交付再收敛。
